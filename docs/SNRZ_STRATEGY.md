# استراتژی SNRZ — خلاصه‌ی قوانین استخراج‌شده از فایل‌ها

منبع: کتاب **SNRZ Strategy — Zindan The Gold Chaser (Captain Masterclass)** + جزوه‌ی کامل مسترکلاس (SNRZ.docx) + صفحات مصور کتاب ۲۰۲۶.

بهترین بازار طبق دوره: **طلا (XAUUSD)**. روی جفت‌ارزها هم کار می‌کند (GBPJPY توصیه شده).

## ۱) اجزای اصلی SNRZ
- **Valid Support (V.S)** و **Valid Resistance (V.R)**
- **Rood Block (R.B)** — ناحیه‌ی سدکننده / Supply
- **Golden Zone** — ترکیب S و R در یک ناحیه (قوی‌ترین زون)
- **SBR / RBS** — تبدیل نقش بعد از شکست (Support→Resistance / Resistance→Support)
- **SRR / RSS** — حمایتی که دو مقاومت شکسته ⇒ زون خرید (SRR)؛ مقاومتی که دو حمایت شکسته ⇒ زون فروش (RSS)
- **Power of Second Touch (PO2)** — مهم‌ترین سیگنال: برخورد دوم به زون
- **Gap Strategy** — فاصله‌ی بین R و S با زاویه‌ی تند (~۴۵ درجه)
- **Liquidity / Imbalance** — Equal High/Low، سویپ و ران

## ۲) قانون طلایی Valid شدن زون (دو حرکت)
```
Valid Zone = First Big Movement + Second Big Movement
```
- **حرکت اول:** قیمت از ناحیه برمی‌گردد، ساختار مقابل را می‌شکند (BOS).
- **حرکت دوم:** قیمت به همان ناحیه برمی‌گردد و دوباره حرکت بزرگ می‌کند.
- اگر فقط یک حرکت باشد ⇒ زون Invalid است و **نباید** روی آن ترید کرد.
- هر دو حرکت باید «بزرگ» (Big Movement) باشند.

## ۳) قانون شکست ۷۵٪ (Breakout)
- کندل صعودی: سایه‌ی پایین حساب نمی‌شود؛ از Open تا High اندازه بگیر. اگر **۷۵٪** آن بیرون زون بسته شد ⇒ شکست تأیید.
- کندل نزولی: سایه‌ی بالا حساب نمی‌شود؛ از Open تا Low اندازه بگیر.
- شکست کامل بدنه (Body کامل بیرون زون) = Run ⇒ ادامه‌ی حرکت.
- فقط سایه بیرون برود و بدنه داخل بسته شود = **Sweep / False Breakout** ⇒ سیگنال برگشت.

## ۴) Inversion (تغییر نقش)
- شکست V.S ⇒ تبدیل به **IVR** (Inversion Valid Resistance) ⇒ زون فروش
- شکست V.R ⇒ تبدیل به **IVS** (Inversion Valid Support) ⇒ زون خرید
- شکست S معمولی ⇒ **SBR**؛ شکست R معمولی ⇒ **RBS**

## ۵) پنج نوع ورود (Entry Types)
1. **V.S / V.R** — برگشت به زون معتبر + رد شدن (Rejection)
2. **RBS** — مقاومت شکسته ⇒ پولبک ⇒ خرید
3. **SBR** — حمایت شکسته ⇒ پولبک ⇒ فروش
4. **IVS** — شکست V.R ⇒ برگشت ⇒ خرید
5. **IVR** — شکست V.S ⇒ برگشت ⇒ فروش

**همه‌ی ورودها نیاز به Confirmation در تایم‌فریم پایین‌تر دارند** (M15 / M5):
- کندل Engulfing به سبک SNRZ (کندل تأیید می‌تواند از کندل قبلی *کوتاه‌تر* باشد)
- Pin Bar / Rejection
- شکست ساختار کوچک (BOS) در جهت ترید
- الگوی QM (Quasimodo) روی زون Inversion

## ۶) قانون برخوردها (Touch Rule)
- برخورد ۱: عادی — برخورد ۲: **قوی‌ترین (PO2)** — برخورد ۳: آخرین فرصت (در تایم‌های بالا فقط ۲ برخورد قبول است).
- بعد از ۳ برخورد احتمال شکست زون زیاد است؛ ترید نکن.

## ۷) تایم‌فریم و قانون Skipping
| زون در | تأیید در |
|---|---|
| Monthly | Weekly → Daily |
| Weekly | Daily → H4 |
| Daily | H4 → H1 |
| H4 | H1 → M30 |
| H1 | M30 → M15 |

قانون: **Timeframe = Pips** (تایم بزرگ‌تر ⇒ تارگت بزرگ‌تر).

## ۸) مدیریت معامله
- **SL:** بیرون زون، زیر/بالای سایه‌ی کندل تأیید (روی Liquidity).
- **TP1:** زون مقابل / لیکوییدیتی نزدیک — **TP2:** زون تایم بالاتر.
- ریسک هر معامله ≤ **۱٪** حساب؛ بعد از 1:1 استاپ را Break-Even کن (Zero Float / Risk Free).
- خلاف روند Daily/H4 ترید نکن («Trend is King»). در زمان اخبار مهم (NFP/CPI) ترید نکن.
- Overtrade نکن: فقط ستاپ‌هایی که ۱۰۰٪ با قوانین منطبق‌اند.

## ۹) چک‌لیست ورود
- [ ] روند مشخص است؟ (HH/HL یا LH/LL)
- [ ] First Movement وجود دارد؟
- [ ] Second Movement وجود دارد؟ (هر دو Big؟)
- [ ] زون درست رسم شده؟ (از کندل کوتاه‌تر)
- [ ] Confirmation در تایم پایین گرفته شد؟
- [ ] SL بیرون زون است؟ RR حداقل 1:1 (ترجیحاً 1:2+)؟
